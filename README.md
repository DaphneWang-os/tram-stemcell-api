# TRAM 干细胞 ICF 评估系统

Technology–Risk Adaptation Model for Stem-Cell Trial Informed Consent

Interactive tool for analyzing stem-cell trial informed consent documents
across five dimensions and the TRAM adaptation model.

## Features

- Query 73 built-in ICF records (five-dimension evaluation)
- Analyze new ICF text (75 rules-based checks)
- TRAM single-study adaptation profile (TCS, R/O/G, Mismatch, gaps)
- TRAM cohort reference coefficients (αR, αO, αG, αM)
